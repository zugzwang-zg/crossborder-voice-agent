# Five-minute demo script

## 0:00–0:40 — Product boundary

Open the dashboard and explain that it turns a fixed bilingual review sample
into traceable operating hypotheses. It does not estimate current market share
or make autonomous product decisions.

## 0:40–1:30 — Start broad, then narrow

Use the common language, star and sentiment controls. Open advanced filters and
choose one aspect or issue. Point out the active-filter strip and remove one
filter without resetting the rest.

## 1:30–2:30 — Inspect an insight

Open AI Insights, select one recommendation and explain its sample scope,
support count, limitations and suggested owner/action. Save it as a comparison
baseline, change one filter and show the delta.

## 2:30–3:40 — Return to evidence

Open the evidence library. Search for a review ID or phrase, sort by relevance,
stars or intensity, and move between pages. Select a long review, use an
evidence chip to jump to highlighted source text, and state that time sorting is
disabled because the current source data has no review dates.

## 3:40–4:30 — Human decision trail

Record a review status, owner, priority and note. Export the feedback log and
explain that it is append-only human workflow data, not a rewrite of model
output.

## 4:30–5:00 — Evidence and limitations

Show the evaluation report and frozen challenge-set status. Close with the
known limits: historical sample, missing product identifiers, uncalibrated
model confidence and the still-unscored two-annotator challenge set.
