## [0.2.0] - 2026-08-13

### Added

- Apache License 2.0 repository licensing and attribution notice.
- Blinded multi-model AI pre-review with role separation, structured evidence,
  escalation rules, audit hashes and an explicit non-human claim boundary.
- Crash-safe AI pre-review manifests, atomic stage persistence, explicit failure
  records and hash-bound run recovery without repeating completed model calls.
- Fail-closed AI review budgets for API calls, estimated/actual tokens and
  pinned-tariff USD cost, including cumulative resume accounting.
- Request-time AI review privacy gates with explicit data classification,
  asserted provider controls, secret blocking, PII redaction and private output.
- Hash-bound AI review runtime identity with SDK, endpoint category, requested
  and provider-returned models, prompt/schema/runner hashes and resume checks.
- Evidence-location schema `1.1` with JSON Pointer source binding, Unicode
  offsets, repeated-text disambiguation and bounded minimal-quote checks.
- Deterministic private release-candidate freezing for all 15 published insights,
  including review-level aggregation consistency checks and source-file hashes.
- Reproducible support-rate audit metadata with an explicit selected-record
  denominator and denominator source-ID hash.
- Public hash-only AI-review attestation without raw inputs or model outputs.

- Machine-readable third-party dependency and asset inventory with personal
  NOTICE ownership, lockfile binding and installed-license audit.
- Canonical review source-data contract with product metadata aliases, explicit
  unknown values, duplicate-ID detection, and input validation.
- Traceable source metadata in each analysis JSONL record.
- Contract tests and Phase 1 baseline report.
- Contribution and security guidance.
- Product and subcategory scope selection in the aggregation layer.
- Sampling metadata, explicit unweighted prevalence boundary, stratum counts,
  and configurable small-sample warnings on reports, insights, and tables.
- GitHub Actions checks for the Python aggregation suite and Dashboard lint/tests.
- Canonical actionable-insight fields for scope, support rate, evidence IDs,
  action type, recommended action, and limitations.
- Dashboard product/subcategory scope controls, missing-scope guardrail, and
  persistent sampling boundary rail.
- README first-screen quick start, CI status, reproducible metrics, and data limits.
- Append-only insight feedback events with status, owner, priority, due date,
  notes and explicit quality flags, stored separately from model output.
- Dashboard human-decision ticket, local history and feedback export.
- Saved insight comparison baselines with added, removed and support-change
  deltas across filters or analysis versions.
- Consolidated data/privacy register and public-demo release checklist.
- Frozen 40-review bilingual challenge input spanning neutral/mixed candidates,
  long reviews, multi-topic reviews and implicit attributes, with zero overlap
  against the original gold set and prompt-development sample.
- Per-class sentiment metrics and confusion matrix, multilabel micro/macro
  scores, and confidence-calibration reporting with an uncalibrated UI policy.
- End-to-end regression from source contract through evaluation, traceable
  insight aggregation, dashboard compaction and append-only reviewer feedback.
- Common/advanced filter hierarchy, removable active-filter chips and resettable
  empty/error states in the analyst dashboard.
- Paginated evidence retrieval with relevance, star and intensity sorting,
  source highlighting and explicit unavailable-date behavior.
- v0.2.0 release-candidate architecture, demo and readiness documentation.

### Changed

- Remediated the formal CrossBorder insight audit by narrowing heterogeneous
  effect claims, separating operational responsibility routes, making content
  recommendations conditional on investigation, and tightening representative
  evidence selection.
- Removed mean model confidence from released insight evidence while retaining
  model confidence only for internal deterministic candidate ordering.
- Applied the `remediation-4` audit findings by removing unsupported cause
  drivers, requiring current product and price substantiation before advertising,
  tightening durability evidence, and treating scent hypotheses as potentially
  overlapping.
- Completed the hash-bound `remediation-4` multi-model AI pre-review with 15
  pass decisions, exact-context reuse for unchanged reviews, and an explicit
  correction manifest for out-of-scope adjudications stopped during execution.
- Added exact-context adjudication carry-forward and pinned the optional OpenAI
  SDK to the formally audited `2.53.0` runtime version.
