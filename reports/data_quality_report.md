# CrossBorder Voice 数据质量报告

## 1. 报告范围

本报告记录步骤 3 对 `data/raw/amazon_reviews_raw.csv` 的清洗、质量标记和验证结果。原始抽样文件保持不变，所有清洗结果单独写入 `data/processed/reviews_cleaned.csv`。

## 2. 清洗结果

| 检查项 | 数量 | 处理 |
|---|---:|---|
| 原始记录 | 1,000 | 保留原文件 |
| 正文为空 | 0 | 若存在则删除 |
| 清洗后完全重复 | 0 | 若存在则保留第一条 |
| 最终记录 | 1,000 | 写入 processed 数据 |
| 规范化异常空白 | 92 | 合并换行、制表符和连续空格 |
| HTML 标签或字符实体 | 0 | 本批次未发现 |
| Unicode NFC 变化 | 0 | 本批次未发生 |
| 标题为空 | 0 | 若存在则保留并标记 |

“完全重复”使用语言、商品 ID、星级、清洗后标题和清洗后正文的组合键判断。不同商品下内容相似的评论不会因此被自动删除。

## 3. 新增字段

清洗文件在原有 7 个字段后增加：

| 字段 | 含义 |
|---|---|
| `char_count` | 清洗后评论正文的 Unicode 字符数 |
| `word_count` | 使用对应语言分词规则计算的正文词数 |
| `language_detected` | 保守启发式语言复核结果：`en`、`es` 或 `uncertain` |
| `language_check` | `match`、`suspected_mismatch` 或 `uncertain` |
| `is_short` | 正文是否少于 10 个词 |
| `is_low_information` | 正文是否少于 4 个词，或内容词少于 2 个 |
| `is_suspected_anomaly` | 是否存在疑似语言标签异常 |
| `quality_flags` | 多个质量标记以分号连接 |

## 4. 质量标记结果

| 质量标记 | 数量 | 比例 | 处理原则 |
|---|---:|---:|---|
| 短评论 | 180 | 18.0% | 保留；后续分析降低细粒度推断强度 |
| 低信息评论 | 2 | 0.2% | 保留；允许标签或证据字段为空 |
| 疑似语言错标 | 0 | 0.0% | 若出现则人工复核，不自动删除 |
| 语言判断不确定 | 66 | 6.6% | 保留；主要由短文本或跨语言共享词导致 |

英语短评论为 92 条，占 18.4%；西班牙语短评论为 88 条，占 17.6%。短评论不等于无效评论，例如一句短评仍可能明确指出“颜色比预期更浅”或“产品使手指染色”，因此本项目采用“标记而非删除”的原则。

## 5. 语言标签检查边界

语言复核采用高辨识度功能词、西班牙语变音符号和少量英语缩写构成的保守启发式规则。它用于筛出需要人工检查的记录，不是独立训练的语言识别模型，也不作为删除数据的依据。

本批次没有出现被规则判定为相反语言的记录，但有 66 条被判为 `uncertain`。这与 MARC 已经过语言识别过滤的来源特征一致，但不能据此宣称语言标签 100% 正确。

## 6. 长度概览

| 语言 | 评论数 | 平均字符数 | 中位字符数 | 平均词数 | 中位词数 |
|---|---:|---:|---:|---:|---:|
| 英语 | 500 | 167.8 | 113.0 | 32.5 | 22.0 |
| 西班牙语 | 500 | 149.1 | 116.0 | 27.7 | 21.0 |

英语评论在本样本中的平均长度高于西班牙语，但中位数接近，说明少数较长英语评论对均值产生了影响。后续聚合分析应同时报告均值和中位数，避免只用平均值概括长度差异。

## 8. 使用限制

MARC 评论采集于 2015—2019 年。本数据适合展示清洗方法、标签设计和系统能力，不应解释为当前市场趋势。原数据经过人为的语言和星级平衡抽样，因此星级比例也不能用于估计 Amazon 平台的自然评论分布。
